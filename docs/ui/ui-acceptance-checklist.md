## 二、全局应用壳与导航 (Shell & Navigation)

- [ ] **移动端底部导航栏 (Bottom Navigation)**:
  - [ ] 屏幕宽度 `< 600px` 时，底部常驻 3 个核心 Tab（冒险大厅、资料库、设置）。
  - [ ] 选中项状态清晰（图标与文字高亮符合主题 Primary 色）。
  - [ ] 切换 Tab 时页面切换流畅，无闪烁且保存各 Tab 独立滚动位置。
  - [ ] 在 320px 宽度下，3 个 Tab 均完整显示，文字不截断、无横向溢出。
- [ ] **中屏导航轨 (Navigation Rail)**:
  - [ ] 屏幕宽度 `600px ~ 1024px`（平板或中屏窗口）时，自动转为左侧紧凑 Navigation Rail。
  - [ ] 图标与文本垂直居中排列，不占用主阅读区宽度。
- [ ] **桌面端侧边栏 (Desktop Sidebar)**:
  - [ ] 屏幕宽度 `>= 1024px` 时，展示完整抽屉侧边栏。
  - [ ] 包含品牌标题、新建冒险快捷入口、历史冒险分类与系统入口。
  - [ ] 侧边栏支持收起/展开折叠，折叠动画平滑不掉帧。

## 三、Adventure Dashboard (冒险大厅) 验收项

### 1. 视觉层级与信息结构 (Content-First Hierarchy)
- [ ] **无 AI SaaS 痕迹**: 移除所有 ChatGPT 式夸张霓虹外框、渐变光晕与大面积营销口号，使用 Noto Serif 衬线书卷大标题与文学化典籍图标。
- [ ] **最近冒险最高优先级**:
  - [ ] 当存在存档时，首屏第一眼呈现“最近冒险”卡片，包含当前世界名、当前场景、上次互动时间。
  - [ ] 点击“继续撰写 / 继续冒险”可毫秒级直达当前冒险会话。
- [ ] **新建冒险极易发现**:
  - [ ] “开启新篇章”与“定制向导”卡片并列呈现，高对比度视觉指引。
  - [ ] 在 320px 屏幕下，两张动作卡片自动竖向折行，不会水平挤压变形。
- [ ] **世界观与角色卡片集**:
  - [ ] 模块标题与图标内敛（`Icons.public_outlined`, `Icons.people_outline`）。
  - [ ] 卡片字数超长时以优雅省略号截断（`TextOverflow.ellipsis`），无破卡 overflow。

### 2. 响应式与极值尺寸
- [ ] **320px 竖屏验证**:
  - [ ] 顶部标题、Hero 区、动作卡片、最近存档、世界/角色列表均完整呈现。
  - [ ] 严格零 `RenderFlex` 溢出黄黑斑马线。
- [ ] **412px 主流机体验**:
  - [ ] 留白自然（`AppSpacing.md` / `AppSpacing.lg`），信息密度舒适，单屏呈现完整概貌。
- [ ] **1440px+ 宽屏桌面验证**:
  - [ ] 整体页面内容受控于 `AppBreakpoints.contentMaxWidth` (1200px) 水平居中。
  - [ ] 左右两侧留有对称呼吸边距，避免宽屏下卡片无限横向拉伸导致眼球疲劳。

## 四、Adventure Session (核心叙事会话) 最高优先级验收

### 1. Session AppBar
- [ ] **长冒险标题与长场景名**:
  - [ ] 标题以 `Flexible` + `TextOverflow.ellipsis` 约束，即使标题长达 30+ 字亦不挤出右侧动作按钮。
- [ ] **模型切换与选择**:
  - [ ] 移除桌面端长期占据空间的硬编码下拉 Pill 框。
  - [ ] 点击顶部右上角菜单中的“模型选择”呼出精致底部抽屉 (BottomSheet)，清晰列出常用模型与当前模型。
- [ ] **右侧操作区 (More Menu)**:
  - [ ] 在 320px 窄屏与 160% 超大字体下，AppBar 右侧菜单点击正常，弹出的 PopupMenu 完整呈现“提示词设置”、“重开冒险”、“设置中心”。
  - [ ] 宽屏模式下常用 RPG 快捷入口（世界地图、任务清单、背包物品）直接平铺于 AppBar，点击响应准确。

### 2. RPG 状态栏 (HUD Bar)
- [ ] **数值与图标完整性**:
  - [ ] 必须同时呈现：地点 (`Icons.place_rounded`)、HP (`Icons.favorite_rounded`)、MP (`Icons.bolt_rounded`)、金币 (`Icons.monetization_on_rounded`)。
  - [ ] 数值变动（扣血、耗蓝、获得金币）时局部即时刷新。
- [ ] **点击交互**:
  - [ ] 单击 HUD 条的任意区域，均能快速呼出完整主角角色卡 (Character Sheet) 模态。
- [ ] **320px ~ 600px 响应式折行**:
  - [ ] 当屏幕宽度 `< 600px` 时，HUD 自动以优雅的两行结构呈现（上行数值 Wrap、下行地点徽章），在 180% 极端大字号下亦保证所有图标与数值 100% 可见且零横向溢出。
  - [ ] 当屏幕宽度 `>= 600px` 时，自动合并为水平单行。

### 3. 互动叙事流 (Narrative Reading Zone)
- [ ] **黄金阅读列宽**:
  - [ ] 桌面端消息正文最大宽度受控于 `AppBreakpoints.narrativeMaxWidth` (760px) 并水平居中，符合经典书籍每行 40-70 个中文字符的舒适眼动范围。
- [ ] **排版舒适度**:
  - [ ] 正文行高 1.6，字体采用系统无衬线或 Noto Sans，段落间距匀称。
  - [ ] 用户指令气泡与叙事正文气泡风格差异鲜明，用户行动右对齐带轻微强调，叙事推演左对齐且有典籍呼吸感。
- [ ] **流式打字 (Streaming)**:
  - [ ] LLM 生成文本时流式打字平滑，无整屏抖动或白屏闪烁。
  - [ ] 正在流式生成时，消息列表随文本自动向上平滑微滚；若用户手动向上滑屏查看历史，自动锁定滚动位置，不强制拉回底部。
- [ ] **空状态 (Blank Slate)**:
  - [ ] 新建冒险无历史消息时，呈现优雅空白引导页与“请输入你的第一步行动”，无冷冰冰的“暂无数据”。

### 4. 输入交互与软键盘 (Input Bar & Soft Keyboard)
- [ ] **移动端软键盘弹出 (关键防破项)**:
  - [ ] 软键盘升起时，输入栏与“发送 / 停止”按钮准确停留在软键盘上方，不被键盘物理遮挡。
  - [ ] 消息列表自动缩减视口高度并允许自由滚动浏览，不产生双重滚动内边距或 `RenderFlex` 溢出。
  - [ ] 点击键盘外区域或向下滚动时，键盘顺畅收起。
- [ ] **快捷 RPG 菜单 (QuickMenu)**:
  - [ ] 输入框左侧提供圆润魔导书图标入口，点击弹出快捷功能：角色卡、背包、任务、地图、字数统计、设置。
  - [ ] 在 320px 屏幕下，输入框与右侧发送按钮挤压比例合理，输入框最小可用宽度保证能看清至少 6 个字。
- [ ] **横屏键盘验证**:
  - [ ] 手机横屏模式下调起输入法，输入框仍占满可用宽度，支持全屏或悬浮键盘输入。

## 五、Character Switcher (多角色切换栏) 验收项

- [ ] **多角色状态支持**:
  - [ ] 无伙伴时：自动隐藏，不留空白高度。
  - [ ] 1 位或多位伙伴时：横向展示角色头像、角色名、阵营立场与 HP 百分比。
  - [ ] 死亡角色：自动灰度显示并标明阵亡状态，禁止作为主控发起行动。
- [ ] **窄屏与大字号**:
  - [ ] 角色名超长时单卡内文本自适应缩写。
  - [ ] 在 320px 屏幕与 160% 字体下，横向滚动手势顺畅，与页面垂直滚动不冲突。

  - [ ] 点击新建进入编辑页面，表单元素完整（名称、描述、词条、权重）。

## 八、Adventure Wizard (定制冒险向导) 验收项

- [ ] **全流程 5 步向导**:
  - [ ] Step 0: 世界观设定（选择预设、手动录入或 AI 辅助）。
  - [ ] Step 1: 角色设计（选择或新建主角，必须至少 1 位主角）。
  - [ ] Step 2: NPC 与伙伴关系（配置角色间羁绊、态度、立场）。
  - [ ] Step 3: 序章剧情描写与初始行动分支。
  - [ ] Step 4: 确认预览与踏入冒险。
- [ ] **自适应 Stepper 布局**:
  - [ ] 屏幕宽度 `< 600px`: 强制渲染为纵向垂直步骤条 (`StepperType.vertical`)。
  - [ ] 屏幕宽度 `>= 600px`: 渲染为横向水平步骤条 (`StepperType.horizontal`)，并且整体受控于 1040px 最大宽度居中。
- [ ] **320px 极端屏安全**:
  - [ ] 角色羁绊行采用响应式 `Wrap`，长角色名互联时不出现任何溢出黄黑条。
  - [ ] 底部操作按钮（下一步、上一步、踏入冒险）在窄屏下自适应换行排列。

## 九、视觉语言与设计系统一致性审计 (Visual System Audit)

- [ ] **配色**:
  - [ ] 浅色模式：暖纸感米白底色，墨色主字，克制朱砂红 / 琥珀橙强调色。
  - [ ] 深色模式：深墨灰底色（`#121212`），无刺眼高饱和霓虹。
- [ ] **圆角与边框 (AppRadius & AppBorders)**:
  - [ ] 遵循统一语义令牌：`sm: 6px` (标签/Chip), `md: 10px` (按钮/输入框), `lg: 14px` (卡片/对话框)。
  - [ ] 杜绝 24px+ 大泡泡糖式大圆角。
- [ ] **阴影与光效**:
  - [ ] 杜绝高斯模糊大发光 (Neon Glow)，仅使用 1px 细微半透明边框划分卡片层级。
