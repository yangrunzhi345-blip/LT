## Android runtime verification

Use the exact ARM64 Release APK on an Android environment supporting ARM64.
The local Android 16 Google APIs emulator reports `x86_64,arm64-v8a` with
`libndk_translation.so`; execution is ARM translation, not a physical ARM phone.
Installing the Release APK succeeds. The initial parallel run exited 137;
retry uses 2048 MB after stopping this project's Gradle daemon.

The production UI discovered the verified installed Kokoro model (205 MB),
initialized Sherpa, synthesized the af_maple preview and completed Android
MediaPlayer playback three times without fallback or crash. The captured
production `cache/lt-tts-*/speech.wav` is mono 16-bit PCM at 24,000 Hz:
60,831 frames (2.534625 seconds), peak 6,477 and 59,442 nonzero samples.

The model was copied from a verified existing install into the read-only
emulator; an Android HTTP model download was not performed in this probe.
Download/resume/error behavior is covered by targeted tests. This is ARM
translation evidence, not a physical ARM handset test. Model artifacts and
