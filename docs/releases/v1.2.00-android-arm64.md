## Installation boundary

Officially signed versions share the same permanent certificate and can update
each other with an increasing versionCode. The old public Debug-signed versions
have a different identity: export/back up data before a user chooses to uninstall
the old package and first install the formally signed version. Never uninstall
automatically or bypass Android signing checks. Emulator validation is ARM64
translation, not physical ARM handset or vivo installer validation.
