## Scope (commits since `v1.3.01`)

Role / state monitoring:

- `4a37af2` feat(state): enforce mandatory monitor evaluation and scope-aware tracking.
  - A `不可忽略项` (critical) monitored field is now explicitly evaluated every turn via a new
    `tracked_evaluations` protocol (`changed` / `unchanged` / `undetermined`). An omitted critical
    evaluation triggers at most one bounded follow-up request and otherwise degrades with
    `critical_evaluation:*` diagnostics; `unchanged`/`undetermined` never write a value, so completing
    an evaluation is never conflated with producing a change.
  - Saving monitoring definitions mid-adventure now idempotently seeds the world/NPC runtime entity a
    new definition needs, so the next turn's settlement can write its overlay without reopening the
    adventure.
  - A worldview definition carries an explicit `scope` (`inherit`/`world`/`characters`/`npcs`): a
    `characters`-scoped general rule binds to every roster character with an independent value; legacy
    definitions without a scope stay world-global. Scope is explicit and never guessed from a name.
- `bd4513c` test(state): trace out-of-scope critical monitors and cover the case.

Resource generation budget:

- `b88aa6f` feat(resources): authorized AI generation may now reach its frozen cumulative ceiling
  `C = floor(T*(100+E)/100)` even when `C` exceeds the resource type's ordinary absolute capacity
  (worldview 60000, character/NPC 24000). Schema v50 adds `resource_blueprints.budget_policy_version`
  so already-confirmed runs keep their original budget; version 1 (legacy) keeps the `min(..., A)` clip.
- `64cb4e0` fix(resources): preserve the per-resource `generationElasticPercent` override across a
  re-confirm (it previously survived a single run only).
- `bcd1dfd` test(resources): consecutive re-plans keep the elastic override.

Documentation only (no runtime behaviour):

- `913a5a1` docs(audit): independent read-only audit of schema v50 migration and elastic budget.
- `76ca400`, `15957dd` docs(risks): risk register updates.
