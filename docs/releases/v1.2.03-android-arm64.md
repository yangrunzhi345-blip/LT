## Fixes in this release

- **Part body generation with a large worldview.** `PartGenerationPromptBuilder`
  truncated the first non-fitting reference paragraph with
  `substring(0, remaining)` without clamping the end index to the paragraph
  length. When that paragraph was exactly one UTF-16 code unit short of the
  remaining budget the truncation threw `RangeError`, which the generation
  error classifier reported as an unknown failure. It was only reachable once
  the reference exceeded `maxReferenceCharacters`, e.g. after associating a
  ~50k-character worldview, which is why generation without a worldview
  succeeded. The end index is now clamped, and boundary plus ~50k-worldview
  end-to-end regression tests were added.
- **Generation failure was labeled "Optimization Failed".** Body generation
  failure and validation/optimization failure are different conditions. The
  Studio status bar and section controls now show a new
  `resourceStatusGenerationFailed` ("正文生成失败") for generation failure across
  all six locales, while validation/optimization states keep the optimization
  label.
