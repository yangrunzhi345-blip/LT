# Runtime state presentation boundary

运行时快照、提交归档和数据库中的 `entityId`、`path`、`revision`、`commitId`、`causeType` 与生命周期枚举属于协议数据。它们继续作为运行时和持久化层的权威值存在，但普通状态页面不得直接展示。

## 唯一展示入口

`lib/features/adventure/presentation/state/runtime_state_presentation.dart` 是状态页面的展示解析入口：

- 已知角色使用冒险配置中的角色名；无法解析时使用实体类型的本地化通用名称。
- 字段路径通过本地化字段标签解析；未知路径回退到“未知状态”，不得回退到路径字符串。
- 阵营、控制者、关系等 ID 字段只展示“已配置”；生命周期和值枚举使用本地化文本。
- 变更原因保留自然语言叙述；检测到协议标记时整段省略，不改写用户原文。

运行时解析器和数据库写入仍使用原始 ID、路径及修订号。展示层只消费解析后的文本，因此不会改变状态归属、回放、并发检查或迁移行为。

## 允许的例外

回滚、保存检查点和比较查询仍把修订号作为内部导航参数传递，但普通页面不把该参数渲染为版本号。用户创建的检查点名称、备注、场景时间和叙事摘要是内容数据，可以正常显示。

## 守卫与回归

`test/architecture/runtime_state_presentation_guard_test.dart` 检查状态展示目录中禁止直接把协议字段传给 `Text`。解析器单元测试覆盖已知名称、未知实体、字段标签、ID 隐藏、枚举和原因抑制；widget 回归测试验证实体详情在原始 ID、路径值存在时仍只显示可读标签。
